# F-04: 근로계약서 자동 생성 API 스펙

## 개요
근로계약서 자동 생성 및 관리를 위한 API

## 인증
모든 API는 JWT Bearer Token을 통한 인증이 필요합니다.

## API 목록

### 1. 계약서 초안 생성

**요청**

```http
POST /api/v1/contracts/
Authorization: Bearer {access_token}
Content-Type: application/json
```

**Request Body**

| 필드 | 타입 | 필수 | 설명 | 제약사항 |
|------|------|------|------|----------|
| employee_id | UUID | O | 직원 ID | 해당 사업장의 직원이어야 함 |
| contract_type | string | O | 계약 유형 | regular, fixed_term, part_time, daily, probation, foreign_worker |
| start_date | date | O | 계약 시작일 | YYYY-MM-DD |
| end_date | date | X | 계약 종료일 | YYYY-MM-DD (기간 정한 계약일 때) |
| work_location | string | O | 근무지 | 1~500자 |
| work_hours_per_week | number | O | 주 근무시간 | 0 < x <= 52 |
| work_start_time | string | O | 근무 시작 시간 | HH:MM (24시간제) |
| work_end_time | string | O | 근무 종료 시간 | HH:MM (24시간제) |
| break_minutes | number | O | 휴게시간(분) | 0~180 (기본값: 60) |
| work_days | string | O | 근무 요일 | 예: 월화수목금 |
| wage_type | string | O | 급여 유형 | monthly, hourly, daily |
| base_wage | number | O | 기본급 | 0보다 커야 함 |
| meal_allowance | number | X | 식대 | 기본값: 0 |
| transport_allowance | number | X | 교통비 | 기본값: 0 |
| probation_months | number | X | 수습기간(월) | 기본값: 0 |
| probation_wage_rate | number | X | 수습급여 비율 | 0 < x <= 1.0 (기본값: 1.0) |
| nda_included | boolean | X | NDA 포함 여부 | 기본값: false |
| non_compete_included | boolean | X | 경업금지 포함 여부 | 기본값: false |

### 2. 계약서 목록 조회

**요청**

```http
GET /api/v1/contracts/?page=1&per_page=20&employee_id={uuid}&status=draft
Authorization: Bearer {access_token}
```

**Query Parameters**

| 파라미터 | 타입 | 필수 | 설명 | 기본값 |
|----------|------|------|------|--------|
| page | number | X | 페이지 번호 | 1 |
| per_page | number | X | 페이지 크기 (최대 100) | 20 |
| employee_id | UUID | X | 직원 ID 필터 | 없음 |
| status | string | X | 상태 필터 | 없음 |

**Response (200 OK)**

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "employee_id": "uuid",
      "employee_name": "홍길동",
      "contract_type": "regular",
      "start_date": "2024-01-15",
      "status": "draft",
      "created_at": "2024-01-15T10:00:00Z"
    }
  ]
}
```

## 에러 코드

| 코드 | 메시지 | 상태코드 | 설명 |
|------|--------|-----------|------|
| E-2001 | 인증이 필요합니다. | 401 | JWT 토큰 없음 |
| E-2005 | 접근 권한이 없습니다. | 403 | 다른 사용자의 사업장/직원 접근 |
| E-3002 | 리소스를 찾을 수 없습니다. | 404 | 사업장/직원/계약서 없음 |
| E-5001 | 최저임금 기준에 미달합니다. | 422 | 최저임금 미달 시 |

## Rate Limiting

| API | 제한 | 시간 윈도우 |
|-----|------|-----------|
| POST /api/v1/contracts/ | 20회 | 1시간 |
| GET /api/v1/contracts/ | 100회 | 1분 |
| GET /api/v1/contracts/{id} | 100회 | 1분 |

## 비즈니스 로직

### 최저임금 검증
- 2026년 최저임금 기준: 시급 10,030원
- 월급: 기본급 / 209시간(월 근무시간)으로 시급 환산 후 검증
- 일급: 기본급 / (주 근무시간 / 5)으로 시급 환산 후 검증
- 시급: 바로 검증

### 계약서 상태
- `draft`: 초안 (생성 직후)
- `sent`: 전송됨
- `signed`: 서명됨
- `expired`: 만료됨
- `terminated`: 해지됨
