### 제약조건 (Constraints)

#### Check Constraints

1. **ck_contract_type**
   - `contract_type IN ('regular', 'fixed_term', 'part_time', 'daily', 'probation', 'foreign_worker')`

2. **ck_wage_type**
   - `wage_type IN ('monthly', 'hourly', 'daily')`

3. **ck_status**
   - `status IN ('draft', 'sent', 'signed', 'expired', 'terminated')`

### 인덱스 (Indexes)

| 인덱스명 | 컬럼 | 설명 |

| contracts_company_id_fkey | company_id | companies | id | NO ACTION |

## 쿼리 예시

### 특정 사업장의 모든 계약서 조회
```sql
SELECT c.*, e.name as employee_name
FROM contracts c
JOIN employees e ON c.employee_id = e.id
WHERE c.company_id = $1
ORDER BY c.created_at DESC;
```

### 특정 직원의 계약서 목록 조회
```sql
SELECT * FROM contracts
WHERE employee_id = $1 AND company_id = $2
ORDER BY created_at DESC;
```

### 만료 임박 계약서 조회 (30일 이내)
```sql
SELECT c.*, e.name as employee_name
FROM contracts c
JOIN employees e ON c.employee_id = e.id
WHERE c.company_id = $1
  AND c.end_date BETWEEN CURRENT_DATE AND (CURRENT_DATE + INTERVAL '30 days')
  AND c.status NOT IN ('expired', 'terminated')
  AND c.expiry_notice_30_sent = FALSE;
```

## 성능 최적화

### N+1 쿼리 방지
- 계약서 목록 조회 시 `selectinload(Contract.employee)`를 사용하여 직원 정보를 한 번에 로드
- SQLAlchemy의 eager loading 활용

### 페이지네이션
- 목록 API에서 반드시 `offset`/`limit` 사용
- 기본값: `page=1`, `per_page=20`
- 최대 `per_page=100` 제한
