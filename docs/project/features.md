## 인수조건

### F-01: 사용자 인증 및 계정 관리

**User Story:** 사장님으로서, 안전하게 계정을 생성하고 로그인하여 서비스를 이용하고 싶다.

- [ ] 이메일/비밀번호로 회원가입 가능
- [ ] 로그인 시 JWT 액세스 토큰(1시간) + 리프레시 토큰(30일) 발급
- [ ] 카카오 OAuth 로그인 지원
- [ ] 토큰 만료 시 자동 갱신 (Refresh Token Rotation)
- [ ] 로그인 시도 5회/분 Rate Limiting (Redis)
- [ ] 비밀번호 bcrypt 해싱 (rounds=12)
- [ ] 로그아웃 시 토큰 무효화

**기술 노트:**
- python-jose로 JWT 구현
- Redis로 Rate Limiting 및 Refresh Token 블랙리스트 관리
- OAuth state 파라미터로 CSRF 방지

### F-02: 사업장 관리

**User Story:** 사장님으로서, 내 사업장 정보를 등록하고 관리하여 노무 서비스를 맞춤화하고 싶다.

- [ ] 사업장명, 사업자등록번호, 대표자명, 업종, 직원 수 입력
- [ ] 사업자등록번호 형식 검증 (xxx-xx-xxxxx)
- [ ] 업종 선택 (제조/요식/소매/서비스/IT/건설/의료/기타)
- [ ] 10인 이상 사업장 자동 감지 → 취업규칙 의무 안내
- [ ] 사업장 정보 수정 가능
- [ ] 사업장 삭제 (Soft Delete)
- [ ] 사업장별 데이터 격리 (company_id 기반 RLS)

**기술 노트:**
- company_id를 JWT payload에 포함
- generated column으로 work_rule_required 자동 계산
- 업종별 맞춤 템플릿 제공을 위한 컨텍스트 활용

### F-03: 직원 관리

**User Story:** 사장님으로서, 직원 정보를 체계적으로 관리하여 근로계약서와 급여 계산에 활용하고 싶다.

- [ ] 직원 등록: 이름, 주민등록번호(암호화), 국적, 고용형태, 부서, 직급, 입사일
- [ ] 고용형태 지원: 정규직/계약직/파트타임/일용직/파견/수습
- [ ] 국적 지원: 한국/중국/베트남/미국/기타
- [ ] 직원 목록 조회 (페이지네이션, 상태 필터)
- [ ] 직원 상세 조회
- [ ] 직원 정보 수정
- [ ] 직원 퇴직 처리 (resign_date 설정, is_active=false)
- [ ] 주민등록번호, 계좌번호 AES-256 암호화 저장

**기술 노트:**
- SQLAlchemy TypeDecorator로 암호화 필드 처리
- employee_id 기반으로 contracts, payslips, work_records 연결
- 퇴직 시 관련 서류 자동 생성 트리거

### F-04: 근로계약서 자동 생성

**User Story:** 사장님으로서, 법적으로 유효한 근로계약서를 쉽게 생성하여 인쇄하고 싶다.

- [ ] 고용형태별 계약서 템플릿 자동 선택
- [ ] 근로기준법 제17조 법정 필수 기재사항 8개 100% 포함
- [ ] 근무 조건 입력: 근무지, 근무시간, 근무일, 임금, 수습 여부
- [ ] 최저임금 기준 미달 시 실시간 경고 (HTTP 422)
- [ ] 주 52시간 초과 시 경고 배너
- [ ] 특약 사항 체크박스: 비밀유지, 경업금지
- [ ] Claude API로 계약서 본문 생성
- [ ] Word(.docx), PDF 다운로드
- [ ] 생성된 계약서 DB 저장 및 직원별 관리
- [ ] 계약 만료일 D-30, D-7 자동 알림
- [ ] 외국인 근로자 다국어 지원 (한/영/중/베트남)

**기술 노트:**
- Claude API 호출 시 PRD Section 6.3 프롬프트 사용
- python-docx로 Word 생성, WeasyPrint로 PDF 변환
- S3 업로드 후 presigned URL 반환 (24시간 유효)
- 노무사 검토 통과율 95% 이상 목표

### F-05: 급여 자동 계산기

**User Story:** 사장님으로서, 복잡한 수당과 공제를 자동으로 계산하여 정확한 급여를 산출하고 싶다.

**지급 항목:**
- [ ] 기본급 (월급제/시급제/일급제 지원)
- [ ] 주휴수당 = 1일 소정근로시간 × 시급 (주 15시간 이상, 개근 시)
- [ ] 연장수당 = 연장시간 × 시급 × 1.5
- [ ] 야간수당 = 야간시간(22:00~06:00) × 시급 × 0.5
- [ ] 휴일수당 = 휴일시간 × 시급 × 1.5 (8시간 이내) / × 2.0 (8시간 초과)
- [ ] 식대, 교통비 (월 20만원 비과세 한도)

**공제 항목:**
- [ ] 국민연금 = 기준소득월액 × 4.5%
- [ ] 건강보험 = 보수월액 × 3.545%
- [ ] 장기요양보험 = 건강보험료 × 12.95%
- [ ] 고용보험 = 월보수 × 0.9%
- [ ] 소득세 = 간이세액표 기준 (가족수 반영)
- [ ] 지방소득세 = 소득세 × 10%

**기능:**
- [ ] 연도별 최저임금, 4대보험료율 자동 업데이트 (DB 관리)
- [ ] 급여 계산 결과 실시간 미리보기
- [ ] 계산 상세 내역 JSONB 저장
- [ ] 최저임금 이하 계산 결과 경고

**기술 노트:**
- 모든 계산은 Decimal 타입 사용 (float 금지)
- 원 단위 절사: 10원 미만 절사
- labor_law_rates 테이블에서 요율 조회
- 통상시급 = (기본급 + 고정수당) ÷ (주 소정근로시간 × 52 / 12 + 주휴수당 시간)

### F-06: AI 노동법 Q&A 챗봇

**User Story:** 사장님으로서, 노동법 관련 궁금한 점을 자연어로 물어보고 즉시 답변을 받고 싶다.

- [ ] 자연어 질문 → AI 노동법 기반 답변 생성
- [ ] 답변에 관련 법령 조항 인용 (근로기준법 제OO조)
- [ ] 면책 문구 자동 삽입 (100% 삽입률 필수)
- [ ] 멀티턴 대화 (질문 맥락 유지, 최대 20턴)
- [ ] 업종/직원 수/고용형태 컨텍스트 반영
- [ ] 위험도 분류 (LOW/MEDIUM/HIGH/EMERGENCY) 자동 태깅
- [ ] 위험도 HIGH/EMERGENCY 시 노무사 연결 CTA 표시
- [ ] SSE 스트리밍으로 실시간 타이핑 효과
- [ ] 질문 히스토리 저장 (로그인 사용자)
- [ ] 자주 묻는 질문 카테고리 빠른 선택 UI

**RAG 구현:**
- [ ] pgvector로 법령 벡터 저장
- [ ] 의도 분류 (임금/계약/해고/휴가/산재/차별/과태료)
- [ ] 관련 법령 벡터 검색 (top-k=3)
- [ ] 검색 결과를 프롬프트 컨텍스트에 주입

**기술 노트:**
- Claude API 호출 시 PRD Section 6.2 프롬프트 사용
- 면책 문구는 시스템 레벨에서 추가 (프롬프트 의존 금지)
- 대화 히스토리 최대 10턴, 각 메시지 500토큰 이하로 트림
- 주요 노동법 100개 시나리오 테스트 정답률 90% 이상

**User Story:** 사장님으로서, 계산된 급여를 법정 명세서 형태로 직원에게 발송하고 싶다.

- [ ] 급여명세서 법정 기재사항 자동 포함 (근로기준법 제48조)
- [ ] PDF 다운로드
- [ ] 카카오 알림톡 발송
- [ ] 이메일 발송
- [ ] 카카오 실패 시 이메일 자동 Fallback (3회 재시도)
- [ ] 발송 상태 추적 (pending/sent/failed)

### F-08: 취업규칙 자동화

- [ ] 업종별 표준 취업규칙 템플릿 (제조/서비스/IT/요식업)
- [ ] 근로기준법 제93조 법정 필수 기재사항 14개 항목 자동 포함
- [ ] 항목별 편집 기능 (리치텍스트)
- [ ] 고용노동부 신고용 커버 서류 자동 생성
- [ ] 버전 관리 (개정 이력 추적)
- [ ] 근로자 과반수 동의 절차 체크리스트 제공

**기술 노트:**

### F-09: 퇴직금/해고 계산기

**User Story:** 사장님으로서, 직원 퇴직 시 정확한 퇴직금을 계산하고 합법적 절차를 안내받고 싶다.

**퇴직금 계산:**
- [ ] 입사일~퇴사일 기반 퇴직금 자동 계산
- [ ] 평균임금 = 최근 3개월 임금 합계 / 최근 3개월 총 일수
- [ ] 퇴직금 = 평균임금 × 30일 × (총 재직일수 / 365)
- [ ] 연차 미사용 수당 자동 계산
- [ ] 상여금 연간 총액의 3/12 반영
- [ ] 퇴직금 지급 기한 안내 (퇴직 후 14일 이내)

**해고 절차:**
- [ ] 계약 종료 유형별 절차 체크리스트
- [ ] 해고 유효 요건 자동 검토 (근로기준법 제23조)
- [ ] 해고예고 의무 안내 (30일 전 예고 또는 30일분 통상임금)
- [ ] 해고 관련 서류 자동 생성 (해고예고통지서, 권고사직서)
- [ ] 실업급여 수급 자격 가이드
- [ ] 위험 케이스(임신/육아휴직/노조활동) 감지 → 노무사 상담 강력 권장

**기술 노트:**
- Claude API로 해고 절차 가이드 생성 (PRD Section 6.5 프롬프트)
- 위험도 HIGH/EMERGENCY 자동 분류

### F-10: 컴플라이언스 대시보드

**User Story:** 사장님으로서, 사업장의 노무 리스크를 한눈에 파악하고 개선하고 싶다.

**리스크 스코어:**
- [ ] 직원별 서류 완비 현황 표시
- [ ] 법 위반 리스크 스코어 자동 계산 (0~100점)
- [ ] 감점 항목: 근로계약서 미작성(-10), 취업규칙 미작성(-20), 급여명세서 미발송(-5) 등
- [ ] 색상 구분: 초록(80~100)/노랑(60~79)/빨강(0~59)
- [ ] 위반 항목 클릭 시 해결 방법 안내

**이벤트 캘린더:**
- [ ] 연간 노무 이벤트 캘린더
- [ ] 계약 만료일 D-30, D-7 알림
- [ ] 급여 지급일 리마인더
- [ ] 월별 리스크 스코어 변화 그래프

**기술 노트:**
- 실시간 스코어 계산 (Materialized View 또는 캐싱)
- 이벤트 알림은 Redis Queue로 비동기 처리

### F-11: 구독 및 결제

**User Story:** 사장님으로서, 필요한 기능을 선택하여 구독하고 싶다.

**플랜:**
- [ ] 스타터(무료): Q&A 10회/월, 계약서 2건/월
- [ ] 베이직(9,900원): Q&A 무제한, 계약서 무제한, 급여 계산
- [ ] 스탠다드(29,000원): 전체 기능, 급여명세서 발송 100건/월
- [ ] 프리미엄(49,000원): 전체 기능, 발송 무제한, 노무사 1회/월 무료

**기능:**
- [ ] 토스페이먼츠 결제 연동
- [ ] 정기 결제 (자동결제)
- [ ] 플랜 업그레이드/다운그레이드
- [ ] 구독 해지
- [ ] 플랜별 접근 제어 미들웨어
- [ ] 구독 만료 전 알림

**기술 노트:**
- 토스페이먼츠 Billing Key로 자동결제 구현
- JWT payload에 plan 정보 포함
- 플랜별 Rate Limiting 적용

### F-12: 노무사 마켓플레이스

**User Story:** 사장님으로서, 복잡한 노무 문제를 전문 노무사에게 상담받고 싶다.

**케이스 분류:**
- [ ] AI가 케이스 복잡도 자동 분류 (LOW/MEDIUM/HIGH/EMERGENCY)
- [ ] HIGH/EMERGENCY 케이스에서 노무사 연결 강력 권장

**노무사 기능:**
- [ ] 노무사 프로필 (전문분야, 지역, 상담료, 평점)
- [ ] 노무사 목록 조회 (전문분야/지역/평점 필터)
- [ ] AI 상담 세션 기반 케이스 요약 자동 생성
- [ ] 화상/유선 상담 예약 시스템
- [ ] 상담료 에스크로 결제
- [ ] 리뷰/평점 시스템
- [ ] 노무사 응답률/완료율 지표

**기술 노트:**
- Claude API로 케이스 요약 생성 (PRD Section 6.6 프롬프트)
- 토스페이먼츠 에스크로 결제
- 노무사 프로필 관리 별도 페이지

### F-13: 근태 관리

**User Story:** 사장님으로서, 직원의 근무 기록을 관리하여 급여 계산에 활용하고 싶다.

- [ ] 근무 기록 수동 입력 (출근/퇴근/휴게시간)
- [ ] 연장/야간/휴일근무 시간 자동 계산
- [ ] 엑셀(xlsx, csv) 근무 기록 일괄 업로드
- [ ] 엑셀 파싱 오류 시 오류 행 번호 명시
- [ ] 월별 근무 기록 요약
- [ ] 직원별 근무 패턴 분석

**기술 노트:**
- openpyxl로 엑셀 파싱
- 근무 기록은 급여 계산 API와 연동
- 근태 데이터는 work_records 테이블에 저장
