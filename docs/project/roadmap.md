# 프로젝트 로드맵

## 개요

노무닥터 프로젝트의 마일스톤별 개발 계획입니다. 총 7개 마일스톤으로 구성되며, 약 6개월간 진행됩니다.

---

## Milestone 0: 프로젝트 기반 구축

**목표:** 개발 환경 설정 및 인프라 구축

**기간:** Week 1

**작업 내용:**
- Docker 개발 환경 구성 (PostgreSQL + pgvector, Redis)
- 프로젝트 스캐폴딩 (Backend/Frontend)
- DB 스키마 설계 및 Alembic 마이그레이션
- CI/CD 파이프라인 구성
- 코드 컨벤션 및 린트 설정

**산출물:**
- docker-compose.yml
- Backend/Frontend 프로젝트 구조
- 전체 DB 스키마 (users, companies, employees, contracts, payslips, chat_sessions 등)
- Alembic 마이그레이션 스크립트
- .env.example

**완료 기준:**
- [ ] docker-compose up으로 전체 환경 기동 가능
- [ ] alembic upgrade head 실행 가능
- [ ] Backend/Frontend 기본 라우팅 작동

## Milestone 1: 인증 및 기본 데이터 관리

**목표:** 사용자 인증, 사업장/직원 관리 기능 구현

**기간:** Week 2

**기능:** F-01, F-02, F-03

**의존성:** M0 완료

### F-01: 사용자 인증 및 계정 관리
- 회원가입/로그인 API
- JWT 인증 (access: 1시간, refresh: 30일)
- 카카오 OAuth 로그인
- Rate Limiting (Redis)

### F-02: 사업장 관리
- 사업장 CRUD API
- 업종/직원 수 기반 컨텍스트 설정
- 10인 이상 사업장 취업규칙 의무 안내

### F-03: 직원 관리
- 직원 CRUD API
- 고용형태별 관리
- 민감정보 암호화 저장

**산출물:**
- /api/v1/auth/* 엔드포인트
- /api/v1/companies/* 엔드포인트
- /api/v1/employees/* 엔드포인트
- 로그인/회원가입 프론트엔드 페이지

**완료 기준:**
- [ ] 이메일/카카오 로그인 작동
- [ ] 사업장 등록/수정/조회 가능
- [ ] 직원 등록/수정/조회 가능
- [ ] API 문서(Swagger) 확인 가능
