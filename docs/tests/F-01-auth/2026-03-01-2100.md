## 6. 기술 노트

### 6.1 테스트 구조

#### Backend 단위 테스트
- **프레임워크**: pytest + pytest-asyncio
- **패턴**: AAA (Arrange-Act-Assert)
- **테스트명**: 한국어, 테스트 대상과 시나리오 포함
- **Mock**: unittest.mock.AsyncMock 사용

#### Backend 통합 테스트
- **프레임워크**: pytest + httpx
- **테스트 클라이언트**: AsyncClient with ASGITransport
- **테스트명**: API 동작 중심

#### Frontend E2E 테스트
- **프레임워크**: Playwright
- **테스트명**: 사용자 시나리오 중심 (한국어)
- **Locators**: `[name="..."]`, `[data-testid="..."]` 사용

### 6.2 수정 사항

1. **python-jose 에러 클래스**
   - `InvalidSignatureError` 대신 `JWTError` 사용
   - `DecodeError` 대신 `JWTError` 사용

2. **테스트 실행 경로**
   - Backend 테스트는 `/backend` 디렉토리에서 실행 필요
